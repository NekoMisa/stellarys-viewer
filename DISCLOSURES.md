# Before installing Stellarys Viewer

**This software is not provided or supported by Linden Lab, the makers of Second Life.**

Stellarys Viewer is an independent, non-commercial hobby project based on
Firestorm 7.2.4.80712. It is also not provided or supported by the Firestorm team.

- **Support:** use [GitHub Issues](https://github.com/NekoMisa/stellarys-viewer/issues).
  The maintainer helps as time permits; there is no guaranteed response time.
  Do not include credentials, private chat or unredacted logs in public issues.
- **Privacy:** read the [Stellarys privacy policy](PRIVACY.md) before installing.
  The policy covers local files, Second Life statistics, inherited network
  services, GitHub update requests and voluntary support submissions.
- **Extra features:** the AMD fix changes rendering on affected meshes.
  Posing other avatars requires explicit permission and a compatible viewer
  (Stellarys or Black Dragon). Resulting poses are local, not synchronised.
  Shot presets restore camera/lens/blur, local lighting and snapshot dimensions
  in the original region; they do not restore poses or save/upload a photo.
- **Limitations:** this is a hobby viewer with an older Firestorm base, not
  guaranteed to have the fixes/features of the latest official viewers. Linux
  builds are experimental. Windows is x64 with AVX2; Linux is native x86_64.
  Builds are unsigned. SHA-256 verifies integrity, not publisher identity.
- **Content and controls:** the viewer can access user-created Second Life
  content, including Moderate/Adult content where your account is permitted.
  Inherited optional RLVa features let compatible scripted content restrict
  controls and may be used with adult content. Follow Second Life's maturity,
  permissions and conduct rules; the viewer does not grant extra access rights.
- **Installation and updates:** installation is user-directed. Update downloads
  and installation require approval. Link registration is optional. Separate
  settings/cache are preserved on updates and by default on uninstall; see the
  platform guide for removal choices. Other viewers' profiles are not removed.

Read and comply with the [Third-Party Viewer Policy](https://secondlife.com/corporate/third-party-viewers),
[Linden Lab Terms of Service](https://lindenlab.com/tos) and
[Second Life Terms and Conditions](https://lindenlab.com/legal/second-life-terms-and-conditions).
The viewer retains the server-directed Terms-of-Service acceptance flow.
Directory listing and Linden Lab approval are not claimed.
