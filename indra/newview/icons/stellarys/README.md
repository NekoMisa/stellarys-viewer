# Stellarys icon

Approved cat-ear outline and silver four-point star, on a midnight-blue tile.
The original generated PNG is `stellarys-icon-master.png`. The icon was generated
with the built-in image-generation tool and selected by the maintainer on
2026-09-29. `Design-Prompt.txt` records the edit prompt. Repository licensing
applies to this new artwork; original upstream icon files remain in their own
folders.

Run `tools/stellarys-branding/prepare_windows_icons.py` with Pillow to regenerate
the Windows ICO, PNG sizes and bitmap. This performs format conversion/resizing
only. Historical `firestorm_` filenames are required by existing resource/build
paths; the artwork and installed application are Stellarys.
